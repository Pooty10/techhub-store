# TechHub Store

This is a demo Best Buy–style storefront built with Next.js and Tailwind CSS.

Features:
- Product browsing by category
- Search and filters
- Product detail pages
- Shopping cart (persisted in localStorage)
- Simulated checkout (no payments)

How to run locally:

1. Clone the repo:
   git clone https://github.com/Pooty10/techhub-store.git
2. Install dependencies:
   npm install
3. Run the dev server:
   npm run dev
4. Open http://localhost:3000

Deploying:
- Recommended: connect this GitHub repository to Vercel (https://vercel.com/new). Vercel will detect Next.js and deploy automatically.
